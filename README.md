Account Verification UI (HTML/CSS/JS)

This project is a responsive and interactive web interface for verifying a user's account via a 4-digit OTP (One-Time Password) code. It mimics the experience of receiving a verification code via SMS and includes several enhanced UI/UX features inspired by modern web apps.

Features

4-digit OTP input with auto focus and input validation

Animated toast notification showing the randomly generated one-time code

Copy-to-clipboard functionality for the generated code

Responsive design with modern Tailwind CSS classes

Custom success and error panels for feedback after code submission

"Send new code" button to regenerate OTP and reset input

Smooth animations and transitions for enhanced user experience

Pure HTML, CSS, and JavaScript — no external libraries


Usage

Ideal for prototyping or integrating into mobile-first web apps or PWA flows that require user verification through numeric codes.
